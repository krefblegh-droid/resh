# Glyph Check

A website for checking whether a font supports a Unicode character.

## Run

Requires Node.js 18+ (no dependencies).

```bash
ADMIN_PASSWORD=your-password node server.js
# open http://localhost:3000
```

- `ADMIN_PASSWORD`: the password for **Edit** and **Add form** (defaults to `changeme`, so set it).
- `PORT`: defaults to `3000`.
- `DATA_DIR`: where characters and images are saved (defaults to `./data`). On a host, point it at a persistent volume.

Data is stored in `data/db.json`, uploaded images go in `data/images/` and font files in `data/fonts/`. Back up `data/` to keep your content.

## Pages

- **Characters** (`#/characters`): every registered character as "U+2588 FULL BLOCK", each linking to its page.
- **Character U+XXXX** (`#/char/2588`): a box with a font dropdown under it. Choosing a font shows that font's image of the character. If a font has no image for this character, the box says so. **Add form** (password) uploads an image for a font.
- **Edit** (password): the Editor, with **Code** (hex, e.g. `2588`) and **Name** (Basic Latin only, auto-capitalised) fields and a **Register** button.
  The Editor also has **Add font**, which uploads a `.ttf` or `.otf` file (up to 30 MB) for the Test font page, and lists added fonts with a Delete button.
- **Test font** (`#/test-font`): pick an added font, type in the preview box and type a text size in pixels (1–500, default 35). With **Show missing characters as tofu** on, characters the font lacks show as boxes instead of being drawn in another font.

On the Add form page, **Unsupported** marks the font as not supporting the character. Every unsupported form shows the same shared image (`public/tofu.png`), so no copy is uploaded or stored for each one.

Saving a form for a font that already has one (uploaded image or Unsupported) replaces the old one, and a replaced uploaded image is deleted.

## Tofu fallback font

`public/tofu-fallback.ttf` maps every character to a box, so the Test font page can show which characters a font lacks. It is generated by `tools/make-tofu-font.py` (needs `pip install fonttools`); you only need to rerun it to change the box's shape.
